# Nemotron Super Messages 历史思考字段兼容

## 问题与修复

`nvidia/nemotron-3-super-120b-a12b:free` 的 Messages 请求包含历史
`thinking` 块但缺少字符串 `signature` 时，Kilo 返回 HTTP 400
`Invalid Anthropic Messages API request`。该模型未进入已有的历史字段兼容名单。

复用现有兼容处理，仅对最新用户消息之前的 assistant 历史思考记录补齐字符串字段。
保留已有字符串签名、思考正文、工具定义、调用与结果、当前用户消息和输出限制。
该模型的 Chat Completions 与 Responses 请求保持原行为；不扩展到其他模型。

## 验证

2026-10-14，通过已有过滤出口向真实 Kilo Messages 接口发送合成请求：

- 基础请求、禁用思考请求、system 块请求均正常出字（各一次）。
- 相同历史记录缺 signature：3/3 返回上述 400，错误详情指向历史块 signature。
- 仅补空字符串 signature：3/3 返回 200 且有非空 text。
- 新增本地回归在修复前失败；修复后历史完整性、未覆盖协议不变、待完成思考不变、
  完整适配器转发并产生有效答案等测试通过。相关既有工具历史、上下文、目标模型测试通过。

线上日志确有相同的通用 Messages 错误，但没有保留该请求的底层字段详情，
因此以上验证证明此兼容缺口可复现并可修复，不证明全部线上 Messages 400 都由它造成。

## 另一个已确认的问题

Nemotron Super 的另一批 400 明确报告 262144-token 上限；请求约 29 万至 95 万 token，
包含文本、工具定义及输出预留。当前源码已有该模型的 262144 上限配置。
完整请求日志未开启，尚不能区分具体请求因工具关联保护、不可裁剪内容还是估算偏差而超限。
本补丁不修改上下文裁剪或丢弃工具定义，不能宣称解决这类错误。
